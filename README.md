# Livogen Health Camp Frontend

## Overview
This is the frontend for Livogen's "12 ka Naara" health initiative.

## Structure
- `index.html` - Main HTML page
- `scripts/impactChart.js` - Chart.js logic
- `styles/custom.css` - Custom styling
- `assets/images/` - Folder for any images you want to use

## How to Run
1. Open `index.html` in your browser.
2. Make edits in a code editor (VS Code recommended).
